## 📌 Цель работы
Получение практических навыков автоматизации процессов первичной классификации и обработки входящих обращений заказчика в службу сопровождения ПО (TSE / L2-L3 поддержка) с использованием специализированного инструмента **[iResolver](https://github.com/kovaloid/iresolver)** на базе технологий обработки естественного языка (NLP) и продукционных экспертных систем.

В качестве целевой программной системы выбран распределенный брокер сообщений **Apache Kafka**.

## 🛠 Стек технологий
* **Платформа выполнения**: OpenJDK 11 (Adoptium Temurin 11.0.25 LTS)
* **Векторизация текстов (NLP / Embeddings)**: Deeplearning4j 0.9.1 (архитектура `ParagraphVectors` / Doc2Vec: PV-DBOW, Skip-Gram, оптимизация Hierarchical Softmax на дереве Хаффмана)
* **Экспертная система**: Apache Drools 7.7.0.Final (KIE Session, диалект MVEL)
* **Интеграционные шлюзы**:
  * Atlassian Jira REST API (выгрузка тикетов проекта Apache Kafka)
  * Confluence REST API (индексация базы знаний и архитектурной документации)
  * Apache PDFBox (индексация официальных руководств Confluent и Cloudera)
* **Шаблонизация отчетов**: Apache Velocity (генерация интерактивного `report.html`)

## 🧠 Разработанные правила экспертной системы (`CustomRules.drl`)

В файле `iresolver_work/rules/CustomRules.drl` реализованы 4 специализированных правила Drools:

1. **Sub-tasks are present**:
   * *Условие*: у тикета есть незавершенные подзадачи (`subtasks.size() > 0`).
   * *Действие*: рекомендация разработчику проверить статус декомпозированных задач перед закрытием тикета.
2. **Open with active comments**:
   * *Условие*: тикет находится в статусе «Open», но инженеры уже оставили более 3 комментариев.
   * *Действие*: рекомендация перевести задачу в статус «In Progress», так как над ней уже ведется активное обсуждение.
3. **High Priority Unassigned Issue**:
   * *Условие*: тикет имеет критический или высокий приоритет (`Critical`, `Major`, `Blocker`), но исполнитель не назначен (`assignee == null`).
   * *Действие*: эскалация тимлиду на немедленное назначение квалифицированного инженера.
4. **No fix version specified**:
   * *Условие*: у открытой задачи отсутствует целевая версия релиза (`fixVersions.isEmpty()`).
   * *Действие*: уведомление о необходимости привязки тикета к ближайшему майлстоуну релиза.

## 🚀 Инструкция по запуску

### Вариант 1: Запуск в один клик (Рекомендуемый)
1. Дважды кликнуть по файлу **`Обновить_отчет.bat`** в корне репозитория.
2. Скрипт автоматически подключит `OpenJDK 11`, выполнит анализ тикетов `KAFKA-17361`, `KAFKA-16800`, `KAFKA-16628` через движок Drools и откроет готовый отчет в браузере.

### Вариант 2: Запуск графического интерфейса
1. Дважды кликнуть по файлу **`Запустить_UI.bat`**.
2. В открывшемся окне нажать кнопку **Run**.

### Вариант 3: Запуск через консоль PowerShell
```powershell
$env:JAVA_HOME = "C:\jdk11"
$env:PATH = "$env:JAVA_HOME\bin;$env:PATH"

cd ".\iresolver_work\bin"
.\run.bat
```

Сгенерированный отчёт будет доступен по пути:  
👉 `iresolver_work/output/report.html`
